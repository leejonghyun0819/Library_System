# 메뉴 기능 구현 현황

## 구현 완료

- 통합자료검색: 실제 도서 검색 API 연결
- 기본정보: 로그인 사용자 정보 조회/수정 API 연결
- 인기순위: 대출/예약 이력 집계 API 연결
- 도서이용정보: 내 대출/예약 목록, 반납, 예약취소 API 연결
- 이용안내: 앱 이용 규칙 안내 화면 구현

## 제외

- 신착자료: 현재 실제 적재 데이터에 등록일, 입고일, 출간일 컬럼이 없어 신착 기준을 만들 수 없으므로 제외

## 인기순위 계산 기준

```txt
인기점수 = 누적 대출 횟수 * 2 + 누적 예약 횟수
```

대출/예약 이력이 쌓이면 `GET /api/books/popular`에서 자동으로 순위가 반환됩니다.
